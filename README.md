# 🚗 React Car Details App

Aplicação React simples que utiliza **props** para exibir uma lista de carros com seus respectivos detalhes, como marca, cor, ano e quilometragem. Também identifica se o carro é **novo** ou **usado**, com base na quilometragem.

---

## 📌 Funcionalidades

- Lista dinâmica de carros com React
- Uso de **props** para passar dados
- Condicional para verificar se o carro é novo ou usado
- Estilização simples com **estilo inline**
- Layout responsivo com `flexbox`

---

## 🛠️ Tecnologias utilizadas

- [React](https://reactjs.org/)
- JavaScript (ES6+)
- CSS inline
- Vite ou Create React App (dependendo da inicialização)
